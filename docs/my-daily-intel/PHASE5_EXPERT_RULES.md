# Phase 5 — 专家模式 / 规则调试器

本阶段让“我的关注”从简单关键词列表升级为可解释、可调试的本地规则系统。

## 已完成

- 专家模式入口：每个关注主题可进入独立规则调试页
- AND：必须包含
- OR：任意包含
- NOT：排除
- 关键词权重：正负分均支持
- 相关度阈值
- 可解释评分：显示命中了哪些词、缺少哪些词、是否触发排除、权重贡献与最终得分
- “测试规则”直接读取 AIHOT 当天精选时间线，不使用静态演示数据
- 测试结果分为“命中的信息 / 未命中的信息”
- 每条结果显示为什么命中或为什么没有命中
- 规则保存在原有个人关注配置中，并继续随 JSON 导出/导入

## 评分规则（第一版）

- 每个 AND 命中：+2
- 每个 OR 命中：+1
- 自定义关键词权重：叠加用户设置的正负分
- 任一 NOT 命中：直接不通过
- AND 缺失：不通过
- 设置 OR 时一个都没命中：不通过
- 最终得分低于阈值：不通过

## 说明

Phase 5 的测试对象是原 AIHOT 当前公开精选时间线，因此它是真实信息池测试，不是手工文本 Demo。

Phase 6 再把这些个人规则接到事件级聚合，让“我的关注”不只匹配单篇资讯，而是匹配和汇总同一事件。
