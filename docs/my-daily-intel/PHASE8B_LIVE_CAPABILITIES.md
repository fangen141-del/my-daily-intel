# Phase 8B — 把“部分完成”变成真正可用

本阶段继续处理 Phase 8 审计中已经有 UI/配置，但尚未完全接线的能力。

## 已完成

### 1. 刷新频率真正生效
主题情报页现在按每个关注主题的 refresh 设置自动重读：
- 实时：每 1 分钟
- 每小时
- 每 6 小时
- 每天
- 手动

页面不可见时不主动重读；用户仍可点击“立即刷新”。

### 2. 关注对象成为一等字段
每个 FocusTopic 新增 kind：
- 主题
- 资产
- 基金
- 股票
- 公司
- 人物
- 国家
- 行业
- 产品
- 其他

旧配置没有 kind 时自动按“主题”兼容，不破坏原 localStorage 数据。

### 3. 官方 / 媒体 / 社交真正分栏
主题情报页新增“来源视角”：
- 官方消息：来自 AIHOT story.officialReports
- 媒体报道：来自当前匹配结果中的 news channel
- 社交讨论：来自当前匹配结果中的 x channel

没有数据时明确显示空缺，不生成假内容。

## 仍未完成

- 来源类型筛选：news / x 可以区分，但 finance / tech / government / research 等还需要后端公开更细的来源元数据。
- 首页编辑：拖动、隐藏、尺寸、显示数量尚未实现。
- 媒体 / 市场观点：仍缺统一结构化观点字段，因此不从标题或摘要猜立场。

这三项继续保持“未完成”，不提前标记。
