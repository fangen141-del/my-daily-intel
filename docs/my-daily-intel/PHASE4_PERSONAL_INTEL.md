# Phase 4 — 我的关注 / 情报主题管理器

本阶段在不破坏 AIHOT 原有精选、热点、日报、主题、搜索与详情体验的前提下，新增浏览器本地的个人关注系统。

## 已完成

- `/focus` 我的关注
- `/focus/manage` 情报主题管理器
- 首页顶部“我的重点关注”
- 桌面侧栏增加“我的关注”
- “我的”页增加“我的关注 / 管理我的关注”
- 主题支持：名称、关键词、排除词、来源类型、重要程度、刷新频率、启用/暂停
- 主题可新增、编辑、删除
- 预设：综合情报、投资者、创业者、科技
- 首次打开默认提供“综合情报”预设，避免空白
- 本地持久化：`localStorage`
- 配置导出：`my-intelligence-config.json`
- 配置导入
- 隐私说明同步更新

## 本阶段明确不做

- AND / OR / NOT
- 关键词权重
- 规则命中测试
- 根据新闻内容计算 relevanceScore
- 同一事件的个人关注聚合
- “为什么重要 / 对我有什么影响”的 AI 计算

这些分别进入 Phase 5–7。

## 不退化要求

原 AIHOT 的以下能力不得因本模块改变：

- 精选 / 全部
- 热点榜
- 事件页
- 日报 / 周报 / 月报
- 公共主题
- 搜索和筛选
- 收藏与已读
- 详情阅读
- 响应式与深浅色
- 现有 API / publication / worker / event grouping

## 技术路径

新增模块：`modules/personal-intel/`

利用 AIHOT 原生 Module 扩展机制注册路由、侧栏、我的页工具入口与 root Top 区域，不重写核心页面。
