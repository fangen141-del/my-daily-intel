# Phase 8C — 最后能力补齐

本阶段完成 Phase 8 审计中最后三项核心缺口。

## 1. 来源细分类筛选

AIHOT 原 sources 表已经保存：
- kind
- tags
- tier / first-party

现在公开卡片安全增加：
- source.kind
- source.tags
- source.firstParty

不会公开：
- feed URL
- 抓取配置
- 管理后台状态
- 健康信息
- 内部 source id

个人关注的来源筛选现在真实参与匹配：

- 新闻媒体 → news channel
- 社交媒体 → x / x_search
- 官方 → firstParty 或“官方”标签
- 研究 → “研究 / 研究机构”标签
- 自媒体 → “个人 / 自媒体”标签
- 财经 → “财经 / 金融”标签
- 科技 → “科技 / 技术”标签
- 政府 → “政府 / 政务”标签
- 自定义 → external 或“自定义”标签

因此，中国大陆后续新增信源时，只要在后台规范维护 tags，不需要修改前端代码。

## 2. 首页编辑

新增本地首页编辑模式：

- 模块：我的重点关注 / 今日热点 / 精选时间线
- 电脑：拖动排序
- 手机：上下按钮排序
- 可隐藏 / 恢复模块
- 一键恢复默认
- 我的重点关注可调整：
  - 标准 / 紧凑
  - 显示 2 / 4 / 6 / 8 个

默认顺序仍保持：
1. 我的重点关注
2. 今日热点
3. 精选时间线

热点和时间线内部 UI 不改，避免破坏 AIHOT 原信息密度。

## 3. 媒体 / 市场观点

不做情绪关键词推断。

AIHOT taxonomy 已有明确 category：
- opinion = 作者的解释、判断、主张、预测、评论或访谈观点

因此：

### 媒体观点
只展示：
- category === opinion

### 市场观点
只展示：
- category === opinion
- 且 source.tags 含“财经”或“金融”

页面明确声明：
这些是来源自身的观点类材料，不代表系统立场，也不自动等同利好 / 利空。

## 最终状态

Phase 8 审计中的三项主要缺口：
- 来源细分类筛选
- 首页编辑
- 媒体 / 市场观点结构化

本阶段已全部接入真实数据和真实交互，不再是占位 UI。
