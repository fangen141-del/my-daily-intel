# Phase 6 — 事件级聚合

本阶段把“我的关注”从单篇资讯匹配升级为事件级阅读。

## 核心原则

不新建相似新闻算法，直接复用 AIHOT 原有：
- fact：同一次真实发生
- group：同一事实的多篇报道
- story：同一具体事件的连续进展

## 已完成

- 新增主题专属情报页：`/focus/:id`
- 先按个人规则匹配原 AIHOT 精选时间线
- 同一 fact 的多篇报道合并
- 同一 story 下的多个 fact 再合并为一个事件
- 显示至少多少篇报道
- 显示一个事件有几个进展
- 显示“为什么与你相关”
- 点击 story 级结果直接进入 AIHOT 原版事件详情页
- 单篇/单 fact 结果仍进入原版文章详情
- 首页“我的重点关注”与“我的关注”列表均改为进入主题专属情报页

## 隐私边界

个人规则仍只存在浏览器本地。

服务端新增的接口只接受公开 fact ID，并返回 AIHOT 已有的 fact → story 映射，不接收用户关键词、权重或关注配置。

## 新接口

`GET /api/personal-intel/story-map?factIds=...`

仅用于把公开 fact 映射到未合并的 story。

## 页面结构

主题专属情报页目前包含：

1. 今日最重要
2. 事件聚合
3. 最新消息

后续 Phase 7 在此基础上增加：
- 时间线
- 来源交叉验证
- 为什么重要
- 对我的影响
- 事实 / 媒体观点 / 系统分析分层
