## 五、社交平台

### 微信公众号

AIHOT 原生支持 `mp_account`。

需要：
`DAJIALA_KEY`

### X

AIHOT 原生支持 `x_search`。

需要：
`SOCIALDATA_API_KEY`

### 抖音 / 小红书 / B站

当前没有原生采集器。

推荐：
- 外部采集脚本
- 标准化输出
- POST `/api/ingest/items`

进入系统后仍可复用：
- 精选
- 事件归组
- 热点
- 我的关注
- 来源过滤

## 六、信源扩展原则

正式交付以后，新信源加入必须满足：

1. 实际服务器可访问
2. 预览能抓到真实文章
3. URL 正确
4. 发布时间正确
5. 没有导航 / 广告污染
6. 连续运行稳定
7. 有明确 tier
8. 有明确 tags

信源数量不是质量指标。
