# 首次部署检查表

适用于：我的每日情报台 Delivery v1.0.0

部署完成后，不要只看到首页能打开就认为成功。按下面顺序检查。

## A. 环境

- [ ] Docker 已安装
- [ ] Docker Compose 可用
- [ ] 服务器磁盘空间充足
- [ ] `.env` 已生成
- [ ] `ADMIN_PASSWORD` 已填写
- [ ] `SESSION_SECRET` 已填写
- [ ] `IMG_PROXY_SIGN_SECRET` 已填写
- [ ] `POSTGRES_PASSWORD` 已填写
- [ ] `LLM_API_KEY` 已填写
- [ ] `SITE_URL` 与实际访问地址一致

## B. 容器

运行：

```bash
docker compose ps
```

确认：

- [ ] db = healthy
- [ ] setup = exited 0
- [ ] api = running
- [ ] worker = running
- [ ] web = running

## C. 后台

打开：

`/admin`

确认：

- [ ] 管理员密码可以登录
- [ ] 后台“信源”页面可以打开
- [ ] 可以看到 seed 信源
- [ ] 可以看到国家统计局
- [ ] 可以看到国家发展改革委
- [ ] 可以看到中国证监会
- [ ] 可以看到少数派
- [ ] 可以看到爱范儿

## D. 采集

查看：

```bash
docker compose logs --tail=200 worker
```

确认：

- [ ] worker 有抓取任务
- [ ] 没有持续重复报数据库错误
- [ ] 没有所有信源都连续失败
- [ ] “全部动态”开始出现内容

某一个外站失败不等于整个系统失败。

## E. 模型

确认：

- [ ] 模型 API 没有 401
- [ ] 模型 API 没有持续 429
- [ ] 有内容完成预筛
- [ ] 有内容完成评分
- [ ] 有内容生成中文标题 / 摘要
- [ ] 有精选内容出现

## F. 事件

观察一段时间后确认：

- [ ] 多来源同一事实能归组
- [ ] 事件页面能打开
- [ ] 热点榜有数据
- [ ] 来源数量正常
- [ ] 官方一手能够识别

## G. 我的关注

确认：

- [ ] 可以打开“我的关注”
- [ ] 可以新增主题
- [ ] 可以编辑关键词
- [ ] 可以设置排除词
- [ ] 可以设置来源类型
- [ ] 可以设置刷新频率
- [ ] 可以设置对象类型
- [ ] 专家模式可以保存 AND / OR / NOT
- [ ] 调试器可以看到命中原因
- [ ] 主题情报页可以打开
- [ ] 官方 / 媒体 / 社交分栏可以显示
- [ ] 首页模块可以排序 / 隐藏
- [ ] 配置可以导出 JSON

## H. 正式上线前

- [ ] 域名解析完成
- [ ] HTTPS 正常
- [ ] `SITE_URL` 改成正式域名
- [ ] 有反向代理时 `TRUST_PROXY=true`
- [ ] 中国大陆公开站点按实际情况完成 ICP
- [ ] 已配置数据库备份
- [ ] 已确认模型预算
- [ ] 已确认付费采集服务预算
- [ ] 已保存管理员密码

## I. 24 小时观察

上线后至少观察一次完整采集周期：

- [ ] 没有 worker 持续崩溃
- [ ] 没有数据库持续重启
- [ ] 重要官方源仍在抓取
- [ ] 没有大量导航 / 广告误抓
- [ ] 日报任务正常
- [ ] 个人关注结果合理

全部通过后，才算“生产运行正常”。
